## 2024-11-20 - Proactive disabled states for Sync Buttons
**Learning:** Transitioning from reactive error states (clicking the sync button and then showing an error if the file is missing) to proactive disabled states (disabling the button until the required file is uploaded) provides a much better UX. It prevents user frustration and clearly communicates requirements upfront.
**Action:** Use disabled states on action buttons that depend on prerequisites (like file uploads) to guide the user naturally.
