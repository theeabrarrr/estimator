# Project: DWP Autonomous Official Pricing & Spare Parts Estimator Engine

## Architecture
- **Framework & UI Layer**: Streamlit (`app.py`), interactive multi-tab interface (`tab_estimator`: Cost & Stock Estimator, `tab_history`: Unit & Customer History, `tab_perf`: Technician Performance).
- **Persistence & DB Layer**: SQLite (`dwp_service.db`) in WAL mode with tables `stock_master`, `parts_master`, `history_master`, and `tech_performance_master`.
- **Precomputed Baseline Cache**: High-speed JSON cache (`data/ground_truth_baseline.json`) generated by `build_baseline.py`.
- **Master Authority Data Sources**:
  1. `data/pdf_extracted_stock_report.csv` (derived from `vp786.pdf`): 518 unique parts with official retail selling prices (`pdf_price`), primary model assignments, and Store 786 stock.
  2. `quality_feedback_report_28SEP2026_142900.csv`: 13,965 closed service complaint records.
  3. `Detail_Collection_28SEP26_023634PM.xlsx`: 6,150 customer billing & cash/warranty receipts.
- **Triangular Ground-Truth Engine**: Fuses Master Price Authority + Field Verification Authority + Chassis & Model Authority, eliminating legacy accounting valuation formula (`AMOUNT / BAL_QTY`) and hardcoded dictionary overrides.
- **Multi-Tier Resolution Engine**: Tier 1 (Exact Model Match), Tier 2 (Platform Series Match), and Tier 3 (Store In-Stock Fallback with strict physical capacity/valve line constraints).

## Interface Contracts
### `etl.py` ↔ `dwp_service.db`
- `ingest_pdf_stock_catalog(csv_path="data/pdf_extracted_stock_report.csv") -> int`:
  - Upserts 518 unique parts into `stock_master` (`part_no`, `item_desc`, `category`, `capacity`, `bal_qty`, `unit_price`, `last_synced`).
  - Sets `unit_price` = `int(round(float(pdf_price)))`.
  - Sets `amount` = `pdf_price * total_stock`.
  - Returns count of ingested parts.

### `build_baseline.py` ↔ `data/ground_truth_baseline.json`
- `build_ground_truth_baseline()`:
  - Phase 1: Ingests `data/pdf_extracted_stock_report.csv` as Master Price Authority.
  - Phase 2: Ingests `quality_feedback_report_28SEP2026_142900.csv` and `Detail_Collection_28SEP26_023634PM.xlsx` as Field Verification Authority.
  - Phase 3: Tokenizes models and cross-references series platforms.
  - Phase 4: Exports atomic JSON to `data/ground_truth_baseline.json`.

### `database.py` ↔ `app.py`
- `fetch_tiered_compatible_parts(raw_model: str, search_query: str = "") -> dict`:
  - Returns dictionary with:
    - `"tier1"`: Exact model components (assigned in official catalog or historical repairs).
    - `"tier2"`: Platform series compatible components.
    - `"tier3"`: Live in-stock store items respecting physical capacity/line constraints.
    - `"metadata"`: Model tokenization, category, tonnage, valve pairing.

## Code Layout
- `config.py`: Business rules, tokenizer, component classification, valve line pairing, category overheads.
- `database.py`: SQLite connection, schema management, multi-tier matching engine (`fetch_tiered_compatible_parts`), global search.
- `etl.py`: Database ingestion routines for official catalog, complaint history, collections, and technician performance.
- `build_baseline.py`: Triangular ground-truth compiler outputting `data/ground_truth_baseline.json`.
- `app.py`: Streamlit frontend consuming `database.py` and `config.py`.
- `test_system_verification.py`: Automated regression and acceptance verification test suite.
